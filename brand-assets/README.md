# Contelligent brand assets

Rebuilt on 1 Nov 2026 from the official logo pack (`DESIGN/3. SVG Format (Web)`). The SVG wordmarks are the designer's files as supplied, with only a title added for screen readers. All letters are vector paths, so no font is needed to display them.

The full rules live in the Contelligent design system (claude.ai artifact). This file is a short summary.

## Colours

| Use | Colour |
|---|---|
| Logo on light backgrounds | Black `#000000` |
| Logo on dark backgrounds | White `#FFFFFF` |
| Page background, alternate sections | Grey `#F3F3F3` |
| Borders and dividers | Grey-line `#D9D9D9` |
| Secondary text on white or grey | `#525252` |

## Fonts

DM Sans for headings and body. DM Serif Display for the occasional display line (for example the home page hero). Never set the word "Contelligent" in a font: always use the wordmark file.

## Files

| File | What it is | Use it for |
|---|---|---|
| `contelligent-logo.svg` | Official wordmark, black on transparent | Website header, documents, anything on a light background |
| `contelligent-logo-white.svg` | Official wordmark, white on transparent | Dark backgrounds (website footer, dark slides) |
| `contelligent-logo-1200.png` | Wordmark, black, 1200 px wide, transparent | Places that don't accept SVG (email signatures, Word, PowerPoint) |
| `contelligent-logo-white-1200.png` | Wordmark, white, 1200 px wide, transparent | Same, on dark backgrounds |
| `contelligent-mark.svg` | Official "C" icon, black, padded to a square | Social profile pictures, app icons, small spaces |
| `contelligent-mark-white.svg` | Official "C" icon, white, padded to a square | Same, on dark backgrounds |
| `favicon.svg` | Browser tab icon | Black C; turns white automatically when the browser is in dark mode |
| `favicon.ico` | Browser tab icon, 16/32/48 px | Older browsers |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | Browser tab icon as PNG, transparent | Tools that ask for a PNG favicon |
| `apple-touch-icon.png` | 180 px, black C on white | iPhone/iPad home-screen icon (Apple doesn't support transparent icons) |
| `icon-192.png`, `icon-512.png` | Black C on white | Android home screen, web app manifest, social profile uploads |

The PNG exports in the designer's logo pack have no transparency and the white versions come out blank, so use the PNGs in this folder instead.

## Rules

- Don't stretch, recolour, redraw or re-type the wordmark. Scale it by width or height only.
- Keep clear space above and below the wordmark of at least the height of the "o".
- On photos or colour backgrounds, use whichever of black or white has more contrast.
