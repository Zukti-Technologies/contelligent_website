# Contelligent brand assets

Built on 27 Oct 2026 from the designer's outlined wordmark (`images/Contelligent Logo.svg`). All letters are vector paths, so no font is needed to display these files.

## Colours

| Use | Colour |
|---|---|
| Logo on light backgrounds | Black `#000000` |
| Logo on dark backgrounds | White `#FFFFFF` |

The company palette is black, grey and white. The grey shade has not been fixed yet.

## Files

| File | What it is | Use it for |
|---|---|---|
| `contelligent-logo.svg` | Wordmark, black on transparent | Website header, documents, anything on a light background |
| `contelligent-logo-white.svg` | Wordmark, white on transparent | Dark backgrounds (website footer, dark slides) |
| `contelligent-logo-1200.png` | Wordmark, black, 1200 px wide | Places that don't accept SVG (email signatures, Word, PowerPoint) |
| `contelligent-logo-white-1200.png` | Wordmark, white, 1200 px wide | Same, on dark backgrounds |
| `contelligent-mark.svg` | The "C" mark, black on transparent, square | Social profile pictures, app icons, small spaces |
| `contelligent-mark-white.svg` | The "C" mark, white on transparent | Same, on dark backgrounds |
| `favicon.svg` | Browser tab icon | Black C; turns white automatically when the browser is in dark mode |
| `favicon.ico` | Browser tab icon, 16/32/48 px | Older browsers |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | Browser tab icon as PNG | Tools that ask for a PNG favicon |
| `apple-touch-icon.png` | 180 px, black C on white | iPhone/iPad home-screen icon (Apple doesn't support transparent icons) |
| `icon-192.png`, `icon-512.png` | Black C on transparent | Android home screen, web app manifest, social profile uploads |

## Rules

- Don't stretch, recolour or re-type the wordmark. Scale it by width or height only.
- Keep clear space around the wordmark of at least the height of the "o".
- On photos or colour backgrounds, use whichever of black or white has more contrast.
- The "C" mark comes from the wordmark's own C, so the two always match.
